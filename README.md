# Gajap Qalam

Цифровая платформа комиксов и республиканского творческого турнира для подростков 10–17 лет. На одной площадке собраны афиша, приём конкурсных работ, магазин цифровых выпусков, онлайн-читалка и личная полка читателя.

**Рабочий сайт:** [gajapqalam.kz](https://gajapqalam.kz)

## Возможности

- защищённая загрузка PDF до 20 МБ и обложки до 2 МБ;
- номер и закрытый код для проверки статуса заявки;
- редакционная панель для отбора и публикации;
- онлайн-библиотека с canvas-читалкой без кнопки скачивания;
- отзывы читателей с предварительной модерацией;
- отдельная коммерческая витрина журналов с бесплатным постраничным превью;
- раздельное хранение preview PDF и полного PDF с серверной проверкой доступа;
- «Моя полка» с купленными выпусками и сохранением последней страницы;
- редакционный выпуск журнала из одного PDF с автоматической сборкой превью;
- описание направлений, календарь сезона и информация для партнёров.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Локальные D1 и R2 запускаются через Vinext/Wrangler. Затем откройте адрес, который появится в терминале, обычно `http://localhost:3000`.

После изменения схемы создайте миграцию через `npm run db:generate`. Публикация Sites применяет новые миграции к размещённой D1; локальную базу при необходимости обновляйте Wrangler-командой для своего preview-окружения.

## Текущий статус

Публичная платформа хранит заявки, каталог и права доступа в D1, а конкурсные и коммерческие файлы — в закрытом R2. Конкурсные работы и коммерческие выпуски разделены: публикация работы ребёнка требует отдельного согласия родителя, а выпуск журнала — подтверждения коммерческих прав редактором. Платёжный провайдер пока не подключён, поэтому интерфейс покупки не списывает деньги и не создаёт покупки. Автоматическое письмо команде включается при наличии `RESEND_API_KEY`; без него новые заявки остаются доступными в редакционной панели.

## Основные маршруты

- `/submit` — подача работы;
- `/status` — проверка статуса;
- `/library` — публичная библиотека;
- `/magazines` — магазин цифровых журналов и превью;
- `/shelf` — личная полка читателя;
- `/admin` — редакционная панель владельца;
- `/privacy` — правила обработки данных.
