# Gajap Qalam

Платформа республиканского творческого турнира для подростков 10–17 лет. Участники подают комиксы, сценарии и концепт-арт, а отобранные работы публикуются в онлайн-библиотеке.

**Рабочий сайт:** [gajapqalam.kz](https://gajapqalam.kz)

## Возможности

- защищённая загрузка PDF до 20 МБ и обложки до 2 МБ;
- номер и закрытый код для проверки статуса заявки;
- редакционная панель для отбора и публикации;
- онлайн-библиотека с canvas-читалкой без кнопки скачивания;
- отзывы читателей с предварительной модерацией;
- описание направлений, календарь сезона и информация для партнёров.

## Технологии

- Next.js 16 и React 19;
- Vinext и Vite;
- TypeScript;
- Cloudflare D1 и R2;
- Drizzle ORM;
- PDF.js;
- Tailwind CSS 4;
- Lucide React.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Локальные D1 и R2 запускаются через Vinext/Wrangler. Затем откройте адрес, который появится в терминале, обычно `http://localhost:3000`.

## Проверка сборки

```bash
npm run build
```

## Текущий статус

Публичная платформа хранит заявки в D1, а конкурсные файлы в закрытом R2. Публикация доступна только редактору и только при отдельном согласии родителя. Автоматическое письмо команде включается при наличии `RESEND_API_KEY`; без него новые заявки остаются доступными в редакционной панели.

## Основные маршруты

- `/submit` — подача работы;
- `/status` — проверка статуса;
- `/library` — публичная библиотека;
- `/admin` — редакционная панель владельца;
- `/privacy` — правила обработки данных.
