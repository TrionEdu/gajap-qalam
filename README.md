# Ғажап Қалам

Сайт республиканского творческого турнира для подростков 10–17 лет. Участники могут представить рассказ или поэму, обложку либо короткий комикс.

**Рабочий сайт:** [gajapqalam.kz](https://gajapqalam.kz)

## Возможности

- описание трёх направлений турнира;
- календарь сезона от регистрации до фестиваля;
- информация для школьных амбассадоров и партнёров;
- архив работ;
- адаптивная форма заявки, открывающая готовое письмо в почтовом клиенте.

## Технологии

- Next.js 16 и React 19;
- Vinext и Vite;
- TypeScript;
- Tailwind CSS 4;
- Lucide React.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Затем откройте адрес, который появится в терминале, обычно `http://localhost:3000`.

## Проверка сборки

```bash
npm run build
```

## Текущий статус

Это рабочий публичный сайт и визуальный прототип платформы. Форма заявки не хранит данные и не загружает файлы: она открывает почтовый клиент с заполненным письмом. База данных, личные кабинеты, авторизация и загрузка конкурсных работ пока не реализованы.
